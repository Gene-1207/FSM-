## Finite State Machine (FSM)

A **Finite State Machine (FSM)** is a computational model used to represent a system that transitions between a finite number of states based on inputs and defined transition rules. FSMs are widely used in digital electronics, embedded systems, communication protocols, and control systems.

### Key Components
- **States:** The different conditions in which the system can exist.
- **Inputs:** Signals or events that influence state transitions.
- **Transitions:** Rules that determine how the system moves from one state to another.
- **Outputs:** Results generated by the system based on its state and/or inputs.

### Types of FSM
- **Moore Machine:** Outputs depend only on the current state.
- **Mealy Machine:** Outputs depend on the current state and current inputs.

### Applications
- Digital circuit design and sequential logic
- Traffic light controllers
- Vending machines
- Communication protocol design
- Embedded systems and hardware controllers

FSMs simplify complex system behavior by dividing it into clearly defined states and predictable transitions.
